# Страница фото и видео

Эта папка предназначена для публикации через GitHub Pages.

После загрузки файлов в репозиторий `work`:
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите `Deploy from a branch`.
3. Выберите ветку `main` и папку `/ (root)`.
4. Нажмите Save.

Страница будет доступна по адресу:
https://petsar38-boop.github.io/work/
